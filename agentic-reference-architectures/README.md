# Agentic Reference Architectures

Agentic Reference Architectures provide reusable cloud-specific blueprints for agentic systems across maturity stages.

They complement:
- Architecture Patterns
- Pattern Packs
- Component Architecture Profiles
- Cost-Aware Selection

They answer:

> What should an agentic architecture look like on this platform at FAST DEMO, MVP, and PRODUCT?

## Platforms

- Azure
- GCP
- AWS
- Microsoft Fabric (data-agent / conversational data profile)

## Maturity model

### FAST DEMO
Goal: prove agentic behavior with the smallest viable architecture.

### MVP
Goal: prove repeatability, integration, observability, and controlled delivery.

### PRODUCT
Goal: prove security, resilience, governance, supportability, and scale.

## Reference variants

Each cloud should support, where relevant:

- single-agent
- RAG agent
- multi-agent
- event-driven agent
- long-running agent
- data agent

## Core rule

> FAST DEMO proves behavior. MVP proves repeatability and integration. PRODUCT proves security, resilience, governance and scale.
