# Definition Packs

Definition Packs establish the minimum information required before architecture and implementation decisions are made.

The goal is not documentation volume.

> Define just enough to remove ambiguity and make the next engineering decision safely.

## Default pack

The default pack is the **Minimum Sufficient Specification (MSS)**.

See [Minimum Sufficient Specification](minimum-sufficient-specification.md).

## Progressive maturity

```text
FAST DEMO
→ minimum definition required to build and demonstrate value

MVP
→ repeatable, testable and traceable definition

PRODUCT
→ operational, security, compliance and resilience definition
```

## Core rule

> Specification grows with product maturity and risk, not with ceremony.
