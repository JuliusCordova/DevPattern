# Enterprise Agentic Architecture

Reusable DevPattern skill for progressively designing and industrializing enterprise agentic systems.

> **Coordinate governed capabilities. Do not build a super-agent.**

This skill extends PA-SDD with:

- 3-level industrialization: **Explore → Govern → Industrialize**;
- 7-plane enterprise agentic reference architecture;
- **PROXI** Decision & Control Plane;
- **Agentic TOM**;
- **Agent Contracts** and related contract family;
- Agent Factory gates **G0–G5**;
- AI Governance + **AI TRiSM**;
- AgentOps + **Agentic Economics**;
- Capability, Knowledge and Model Routing;
- RAG + GraphRAG + semantic/structured knowledge;
- MCP + A2A + OpenTelemetry;
- Azure/GCP/AWS/Fabric portability.
