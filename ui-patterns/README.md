# UI / UX Pattern Packs

UI / UX Pattern Packs define reusable interaction and usability guidance for DevPattern products.

They are selected like other Pattern Packs: only when they reduce user friction, ambiguity, error risk, or support cost.

## Categories

```text
ui-patterns/
├── usability/
├── interaction/
├── agentic-ui/
└── executive-ui/
```

## Progressive maturity

### FAST DEMO

Minimum:
- usable primary flow;
- Nielsen baseline;
- loading / success / error states;
- clear primary action;
- no avoidable cognitive clutter.

### MVP

Add:
- responsive behavior;
- form validation;
- empty states;
- consistent navigation;
- accessibility baseline;
- usability testing on representative users;
- keyboard behavior where relevant.

### PRODUCT

Add where required:
- explicit WCAG target;
- design system;
- analytics/telemetry for UX;
- localization;
- advanced accessibility;
- performance UX;
- cross-channel consistency.

## Key rule

> A FAST DEMO may be visually simple, but it must not be confusing.
