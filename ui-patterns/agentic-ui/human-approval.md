# Agentic Human Approval UI

## Use when

An agent proposes a write, irreversible, financial, legal, privileged or otherwise consequential action.

## Before approval show

- proposed action;
- affected entity/resource;
- why the action is recommended;
- material inputs;
- policy/risk flags;
- rollback/reversibility when applicable.

## After approval show

- execution status;
- outcome;
- evidence/audit identifier.

## Key rule

> Human approval is a control boundary and the UI must make that boundary explicit.
