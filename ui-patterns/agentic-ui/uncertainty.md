# Uncertainty Pattern

## Intent

Communicate uncertainty when it materially changes user decision-making.

## Do

- distinguish known vs inferred information;
- show missing evidence;
- flag conflicts in sources;
- offer verification or human review where appropriate.

## Avoid

- fake numeric confidence;
- vague disclaimers on every answer;
- hiding important uncertainty.

## Key rule

> Communicate uncertainty only when it helps the user make a safer or better decision.
