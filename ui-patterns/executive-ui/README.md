# Executive UI Patterns

Executive interfaces should optimize for decision clarity rather than information density.

## Common patterns

- decision cards;
- exception-first dashboards;
- progressive disclosure;
- trend + threshold + action;
- explicit recommendation/evidence separation.

## Reference structure

```text
What happened?
     ↓
Why does it matter?
     ↓
What needs attention?
     ↓
What action is available?
     ↓
Supporting detail on demand
```

## Key rule

> Executives should see exceptions, decisions and consequences before implementation detail.
