# UI Pattern Selection Guide

UI patterns are selected from the user task and product behavior.

## Intake / workflow application

Recommended starting set:
- Nielsen baseline;
- forms;
- feedback states;
- approvals;
- cognitive load.

## Agentic assistant

Recommended starting set:
- Nielsen baseline;
- agentic UI baseline;
- tool progress;
- citations;
- uncertainty;
- human approval when consequential.

## Executive application

Recommended starting set:
- Nielsen baseline;
- executive UI;
- exception-first presentation;
- progressive disclosure;
- decision-focused summaries.

## FAST DEMO rule

Do not build a design system first.

Select only the patterns required to make the primary scenario understandable and testable.

## MVP rule

Introduce consistency, accessibility, responsive behavior and representative usability testing.

## PRODUCT rule

Introduce a formal design system only when reuse, multi-team development or product scale justifies it.
