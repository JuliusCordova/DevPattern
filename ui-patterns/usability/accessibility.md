# Accessibility Pattern

## Intent

Ensure the product can be used by people with different visual, motor, auditory and cognitive capabilities.

## FAST DEMO

Minimum:
- semantic labels;
- readable contrast;
- keyboard-reachable critical actions;
- visible focus where applicable;
- error messages not communicated by color alone.

## MVP

Add:
- representative keyboard testing;
- screen-reader checks on primary flow;
- semantic structure;
- form labels/instructions;
- responsive zoom behavior.

## PRODUCT

Define and validate an explicit accessibility target, normally aligned to current WCAG guidance required by the product context.

## Key rule

> Accessibility is a functional quality attribute, not a visual polish activity.
