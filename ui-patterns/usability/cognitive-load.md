# Cognitive Load Pattern

## Intent

Minimize unnecessary mental effort while users complete a task.

## Practices

- one clear primary action per decision point;
- progressive disclosure;
- meaningful grouping;
- defaults where safe;
- recognizable domain language;
- avoid exposing implementation detail;
- preserve user context across steps;
- show summaries before consequential actions.

## FAST DEMO

Prioritize the happy path and remove non-essential options.

## MVP

Add advanced options through progressive disclosure.

## PRODUCT

Measure task completion, abandonment, error/rework and repeated support needs.

## Key rule

> Complexity in the domain does not require complexity in the interface.
